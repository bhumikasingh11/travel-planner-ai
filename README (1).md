## 🎯 Features
- AI-generated personalized itineraries
- Budget calculation in Indian Rupees (₹)
- 5 travel styles support
- Downloadable trip plans

## 🛠️ Tech Stack
- LangChain + Groq API (LLaMA 3.3 70B)
- Gradio UI
- Python
